### Task 1: Fix Footer Service Links
**File:** `client/src/components/Footer.tsx`
**Lines:** 28-33

**Problem:** `<li>` elements have `cursor-pointer` class but no navigation logic.

**Fix:** Wrap each service item in a `<Link>` component or add `onClick` handlers:

```tsx
// From:
<li className="hover:text-foreground transition-colors cursor-pointer">SaaS Development</li>

// To:
<li>
  <Link to="/saas-development" className="hover:text-foreground transition-colors">
    SaaS Development
  </Link>
</li>
```

**Mapping:**
- SaaS Development → `/saas-development`
- AI Automation → `/ai-marketing`
- Local SEO → `/#services` (no dedicated page exists)
- Consulting → `/#contact` (consultation CTA)
