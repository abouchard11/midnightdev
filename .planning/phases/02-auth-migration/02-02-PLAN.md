<task type="auto">
  <name>Task 2: Delete custom useAuth hook and update components</name>
  <files>client/src/_core/hooks/useAuth.ts, components using useAuth</files>
  <action>
1. DELETE `client/src/_core/hooks/useAuth.ts` (replaced by Clerk hooks)

2. Find all usages of the old useAuth hook:

   ```bash
   grep -r "from.*useAuth" client/src/
   grep -r "useAuth()" client/src/
   ```

3. For each component using the old hook, replace with Clerk pattern:

   ```tsx
   // OLD
   import { useAuth } from "@/_core/hooks/useAuth";
   const { user, loading, isAuthenticated, logout } = useAuth();

   // NEW
   import { useAuth, useUser, useClerk } from "@clerk/clerk-react";
   const { isSignedIn, isLoaded } = useAuth();
   const { user } = useUser();
   const { signOut } = useClerk();
   ```

4. Update any auth-dependent UI:
   - `loading` → `!isLoaded`
   - `isAuthenticated` → `isSignedIn`
   - `logout()` → `signOut()`
   - `user?.name` → `user?.firstName` or `user?.fullName`

5. REMOVE any `redirectOnUnauthenticated` logic — use Clerk's `<RedirectToSignIn>` or `<SignedOut>` instead:

   ```tsx
   import { SignedIn, SignedOut, RedirectToSignIn } from '@clerk/clerk-react'

   <SignedIn>
     <ProtectedContent />
   </SignedIn>
   <SignedOut>
     <RedirectToSignIn />
   </SignedOut>
   ```

   </action>
