## Tasks

### Task 1: Delete Unused Manus Service Files

Delete the following files that are defined but never called:

```bash
rm server/_core/llm.ts
rm server/_core/imageGeneration.ts
rm server/_core/voiceTranscription.ts
rm server/_core/map.ts
rm server/_core/dataApi.ts
rm server/storage.ts
```

### Task 2: Delete Manus Debug/Config Directories

Remove Manus-specific directories:

```bash
rm -rf client/public/__manus__/
rm -rf .manus/
rm -rf .manus-logs/
```

### Task 3: Update vite.config.ts

Remove Manus-specific code from vite.config.ts:

1. Remove `vitePluginManusRuntime` import
2. Remove `vitePluginManusDebugCollector` function (lines 11-151)
3. Remove both plugins from the plugins array
4. Remove Manus-specific `allowedHosts` entries

Final vite.config.ts should only have:

- `react()`, `tailwindcss()`, `jsxLocPlugin()` plugins
- Standard resolve aliases
- Standard server config with `localhost` and `127.0.0.1` hosts only

### Task 4: Remove Manus Runtime from package.json

Remove `vite-plugin-manus-runtime` from devDependencies:

```bash
pnpm remove vite-plugin-manus-runtime
```
